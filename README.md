# QORVEX · Manufacturing Intelligence Engine

Versión web publicada en GitHub Pages: https://charliealberth2805-svg.github.io/Qorvex/

- Abrir en **Microsoft Edge o Google Chrome** (Windows).
- Botón **Conectar carpeta** → elegir la carpeta compartida **Data Base** (sincronizada con OneDrive/SharePoint).
- Este repositorio solo contiene el programa. **Los datos nunca se suben aquí**: viven en la carpeta compartida.

## Quién escribe cada archivo de Data Base
| Archivo | Lo escribe |
|---|---|
| Validacion_TAB1/2.xlsx, Secuencia_TAB1/2.xlsx | Solo QORVEX MOBILE de esa tableta |
| Validacion.xlsx, Secuencia.xlsx | Solo QORVEX (importar / complemento / ediciones de filas propias) |
| Correcciones_Motor.xlsx | Solo QORVEX: correcciones a capturas de tabletas (solo agrega filas) |
| Planes Generales.xlsx, Pulls.xlsx | Solo QORVEX |
| Respaldos_Motor/ | Copias de seguridad automáticas |
